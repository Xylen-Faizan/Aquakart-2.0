# AquaKart 2.0 Launch Video Plan

**Style:** polished + cinematic, startup-launch quality
**Format:** landscape 16:9
**Length:** ~22 seconds
**Core message:** *Water delivery isn't just ordering a jar — AquaKart connects the customer, supplier and delivery fleet in one system.*

## Creative Direction
Premium startup launch film, cinematic but product-first. Do not make this a generic SaaS montage. The video should communicate the actual AquaKart operating loop.

## Primary Story
Customer needs water → discovers product/supplier → places order → AquaKart dispatch logic searches for an available vehicle → order is assigned/tracked → supplier/fleet handles the delivery.

Use the REAL AquaKart UI from the repository wherever possible.

## Key Source Screens/Components
* Customer home
* Customer search
* Product listing/detail
* Checkout
* Dispatch searching state
* Order tracking
* Supplier routes/fleet
* Opportunistic order offer
* Customer orders/history

## Differentiators
* **First differentiator:** The checkout flow has a real dispatch mode when no explicit supplier is selected. Show the “Finding a delivery vehicle…” state as a key moment. Then transition into the order tracking experience.
* **Second differentiator:** The supplier route interface includes vehicles, driver/helper assignment, route progress, GPS freshness, ETA, and opportunistic delivery offers. Briefly show this operational layer.

## Tone
Confident, premium, cinematic, modern Indian consumer-tech startup.
Avoid exaggerated invented claims, fake metrics, fake customer testimonials, or generic phrases such as “streamline your workflow”.

## Visual Rules
* Reuse real AquaKart colors, typography, icons and screenshots/components.
* Avoid replacing the actual UI with invented mockups.
* Keep all text readable.
* Use motion, simulated taps, zooms and transitions rather than static screenshot slides.
* Every frame should look presentation-ready.
* No personal information, secrets, API keys, real customer names, email addresses or private data may appear.
* Use fictional/demo data when necessary.

## Audio
Modern cinematic electronic beat with restrained UI click / confirmation accents.
Use subtle sound design for search, assignment, and final logo lockup.
Keep music underneath the interface visuals.
